# 证件照/图片资料像素初审方法（无视觉模型）

审核证件照（红底、有领）等图片上传时，如果环境没有视觉工具/多模态能力，用像素分析代替。本方法在 2026-08 会话中实测通过。

## 1. 识别真实文件格式（WeCom 上传是 .bin）

WeCom 网关收到的图片附件保存为 `/opt/data/cache/images/*.bin`，扩展名不反映真实格式。`file` 命令可能不存在，用 Python 读文件头 magic bytes：

```python
with open(path, 'rb') as f:
    head = f.read(8).hex()
# ffd8ff... = JPEG, 89504e47 = PNG, 25504446 (%PDF) = PDF
```

实测：`ffd8ffe1 00824578 6966` = JPEG（带 Exif 头）。

## 2. OCR 对人像照无效

rapidocr-onnxruntime 对纯证件照（人像 + 纯色背景）基本识别不出文字，实测只输出一个孤立的 "9"。**不要**把 OCR 结果当作证件照审核依据；OCR 只对含文字的图片（护照页、银行流水截图、AKTA 扫描件）有用。

## 3. 红底判定（PIL 颜色网格）

- 无视觉模型时，把图片缩小到网格（如 20x28），逐格采样颜色，按阈值分类：
  - `R` = r>200, g<80, b<80（正红背景）
  - `W` = r,g,b 均 >225（白色/衣领）
  - `s` = r>160, 120<g<200, b<150（肤色）
  - `K` = 均 <110（深色头发）
- 红底证件照特征：图片顶部/两侧大面积 `R`，中部 `K`（头发）+ `s`（脸）+ `W`（衬衫）。
- 脚本 `scripts/verify_id_photo.py` 直接输出红底判定（顶部 15% 区域 60 格采样 ≥40 格为红）。

## 4. 有领判定（领口区域裁剪放大）

- 领口大约在图片高度 68%-88%、宽度 25%-75% 区域。裁剪后放大（如 40x24 网格）查看。
- 有领特征：两侧为白色 `W`（衬衫/领子），中间有肤色 `s`/`g` 的 V 形开口（颈部到胸口）。
- 无领/圆领特征：领口区域是纯色（如 `W` 或 `K`）平铺，没有 V 形肤色开口。
- 有领 + 红底 + 免冠正脸 = 证件照通过；白底/蓝底、无领、戴帽、遮挡面部 = 不通过（原因写具体违反点）。

## 5. 环境依赖

系统 python3 无 PIL 且受 PEP 668 保护，用 uv 建独立 venv：

```bash
uv venv /tmp/ocr-venv
uv pip install --python /tmp/ocr-venv/bin/python rapidocr-onnxruntime
# rapidocr 会顺带安装 Pillow；只做像素分析也可以只装 pillow
```

## 判定输出格式（供 SKILL.md 主流程引用）

- 证件照通过：`✅ 个人证件相片电子档（红底、有领）：<文件名>`
- 不通过：`❌ <文件名>` + `**原因：...**`（如 "证件照不是红底，且穿着无领服装"）
